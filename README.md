# Git and GitHub Reference

### [Visit the live site ↗](https://tidyweb.github.io/git_and_github/)


A beginner-friendly reference explaining Git and GitHub in plain English, from opening a command-line interface and configuring Git to publishing, cloning, and updating a project.

## View the guide

Open `index.html` in a web browser, or use the published GitHub Pages site.

No installation or build process is required. The page uses Google Fonts when an internet connection is available and remains readable with fallback fonts if they cannot load.
